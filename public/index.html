数据与同步

本地收藏

收藏和聆听记录保存在当前浏览器。清理网站数据会删除本地收藏，建议定期导出备份。

导入时合并收藏，同一唱片保留更新的记录（含删除记录）。

Supabase 云数据库 可选

填入你自己的 Supabase 项目地址和 anon key。应用使用匿名登录，不读取或保存 Supabase 密码；点击“同步收藏”才会上传本地唱片记录。

未配置云端数据库；本地收藏和 JSON 备份仍然可用。

首次使用前，在 Supabase SQL Editor 执行项目内 supabase/migrations/001_library.sql，并在 Authentication → Providers 开启 Anonymous。

云同步文件夹 OneDrive / Dropbox

选择一个已经由 OneDrive、Dropbox 或坚果云同步的文件夹，唱片墙会自动保存一份副本。应用不会接触你的云端账号密码。

关于唱片信息

元数据来自 MusicBrainz 与 Apple Music 公开目录；新发行会由 Apple Music 补齐。封面由 Cover Art Archive、Apple Music 与网易云音乐补全，支持简繁体、空格、大小写、艺人别名及常见版本名称匹配。无法匹配时显示黑胶占位图。封面仅供个人收藏展示使用。
